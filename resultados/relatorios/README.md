# Relatórios

Os PDFs desta pasta são documentos narrativos.. A referência numérica atual é `../consolidacao_confiavel_20261103/resultados_fewshot_fonte_unica.xlsx`..

- `entendendo_resultados_fewshot.pdf`: explicação dos testes recentes e hipóteses..
- `relatorio_fewshot.pdf`: relatório consolidado até 02/11/2026..
- `anteriores/pdf/`: versões históricas e resumos curtos..

Os relatórios não estão errados por apresentarem números diferentes quando o escopo muda.. Por exemplo, 76,05% é a média do DGCG 4–6 nos 27 protocolos; 75,14% é a reprodução de um único protocolo 5w5s10q.. Consulte o grupo de comparação na planilha antes de usar um valor..
